# Raw data

The ABN Bulk Extract isn't stored in the repository (two zip files, about 500 MB each, 12.7 GB of XML).

To rebuild the processed data:

1. Go to https://data.gov.au/data/dataset/abn-bulk-extract
2. Download **ABN Bulk Extract Part 1** and **Part 2** (`public_split_1_10.zip`, `public_split_11_20.zip`).
3. Put both zip files in this folder. Don't unzip them.
4. Run `python run_analysis.py --rebuild`.

`src/extract.py` reads the XML straight from the zips and writes `companies_full.csv.gz` here
(4.09 million private companies, about 120 MB). It takes about 2 minutes on 4 cores.

The extract used for the published results was generated by the ABR on **21 October 2026**.
The ABR publishes a new extract every week, so a rebuild with a newer extract gives slightly
different numbers.
